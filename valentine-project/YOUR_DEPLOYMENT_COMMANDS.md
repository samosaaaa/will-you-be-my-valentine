
## Deploy Now - Run These Commands:

### Step 1: Navigate to your project folder
```bash
cd valentine-project
```

### Step 2: Initialize git (if not already done)
```bash
git init
git add .
git commit -m "Valentine surprise for Archita 💝"
```

### Step 3: Connect to your GitHub repo
```bash
git remote add origin https://github.com/samosaaaa/will-you-be-my-valentine.git
git branch -M main
git push -u origin main
```

### Step 4: Install dependencies
```bash
npm install -g pnpm
pnpm install
```

### Step 5: Deploy to GitHub Pages! 🎉
```bash
pnpm run deploy
```

## After Deployment:

Wait 1-2 minutes, then visit:
